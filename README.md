# Time Tools

타이머, 스톱워치, 뽀모도로 기능을 한 번에 제공하는 SvelteKit 기반 타이머 웹 앱 Time Tools입니다.  
다크 모드 지원, 상단 네비게이션, 부드러운 페이지 전환 애니메이션을 제공합니다.

## 기능

- 타이머
  - 시:분:초 설정
  - 시작 / 일시정지 / 초기화
- 스톱워치
  - 경과 시간 측정
  - 랩 기록 무제한 측정
  - 시작 / 일시정지 / 초기화
- 뽀모도로
  - 집중 시간 / 휴식 시간 설정
  - 세션 진행 상태 표시
- 공통 UX
  - 상단 네비바에서 타이머 / 스톱워치 / 뽀모도로 이동
  - 왼쪽 상단 로고를 클릭하면 홈으로 이동
  - 다크 / 라이트 모드 토글
  - About 페이지에 뽀모도로 기법 설명란 추가
  - 페이지 전환 시 슬라이드 애니메이션

## 기술 스택

- Framework: SvelteKit (Svelte 5, runes)
- Language: JavaScript
- Build Tool: Vite
- 스타일: CSS (`app.css` 커스텀 스타일)
- AI: sperplaxity pro
